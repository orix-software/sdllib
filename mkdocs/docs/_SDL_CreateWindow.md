## SDL_Window* SDL_CreateWindow(const char *title, unsigned char x, unsigned char y, unsigned char w, unsigned char h, unsigned char flags);


***Description***

Create a window with the specified title and flags.

***Input***

* title The title of the window.
* x The x position - NOT USED in this implementation.
* y The y position - NOT USED in this implementation.
* w The width - NOT USED in this implementation.
* h The height - NOT USED in this implementation.
* flags Window creation flags.

***Returns***

* A pointer to the created SDL_Window, or NULL on failure.
